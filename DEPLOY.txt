E-REPORT/SAGS V4.4.0 · FORM MANAGER + REALTIME LITE

Upload the CONTENTS of this folder to the GitHub Pages root.

MAIN CHANGES
- KẾT SỔ realtime event is pointer-only (no full payload in closeout/latest or closeout_events).
- No 72-hour / 80-event replay on F5. Live listeners start around the current session only.
- Canonical KẾT SỔ stays in Firestore; payload is fetched by exact docId only when a live event or matching FINAL needs it.
- Event TTL: 30 minutes. ACK cleanup target: 3 minutes. AD/PVHK opportunistic cleanup every 15 minutes.
- AD manual cleanup removes closeout broadcast history + ACK without deleting canonical Firestore KẾT SỔ.
- New AD Form Manager: upload/replace page images, select existing assets, add/drag/resize fields, multi-select alignment, undo/redo, local IndexedDB image drafts, export ZIP + registry.
- Custom forms use one generic runtime engine from forms.registry.json; no per-form JS file is required.
- Uploaded form images are exported as separate page files (not base64) so Service Worker SHA-256 delta only downloads changed images.

IMPORTANT
GitHub Pages is static. Client-side TTL cleanup happens when an authorized browser is online. Even if nobody is online, expired events are ignored and are pointer-only, so they cannot recreate the old ~21 MB F5 replay.
